# Universal Coding Agent Onboarding Protocol

[Documentation](../README.md) / [Getting Started](QUICKSTART.md) / [Onboarding Protocol](ONBOARDING_PROTOCOL.md)

**A deterministic 3-stage interview protocol (Inform -> Confirm -> Build) guiding individuals and companies to launch their personalized operating system across Google Antigravity, Cursor, and Claude Code.**

---

## The 3-Stage Onboarding Standard

```

STAGE 1: INFORM Present architectural choices & understand user intent.




STAGE 2: CONFIRM Multi-choice validation of selected domains & rules.




STAGE 3: BUILD Deterministic generation of config, DB schema & playbooks.

```

---

## How It Works Across IDEs

### 1. Google Antigravity
Google Antigravity natively activates `.agents/skills/user-onboarding/SKILL.md` whenever you ask to set up or onboard. It leverages interactive multiple-choice modals (`ask_question`) to guide you without command-line friction.

### 2. Cursor IDE
Cursor reads `.cursorrules` located in the workspace root. When you open Cursor and type `"Set up my OS"`, Cursor executes the 3-stage interview protocol and generates your personalized preferences.

### 3. Claude Code
Claude Code reads `CLAUDE.md`. The interview protocol runs deterministically in terminal chat, walking you through life compass domains or engineering team standards.

## Operating Mode Interview Questions

During onboarding, the agent asks 3 core calibration questions:

### Question 1: System Purpose
* **Option A**: Personal Chief of Staff (Life goals, Socratic reasoning, career compounding, mobile capture).
* **Option B**: Company Living Wiki (Engineering standards, PR invariants, post-mortem scars, async standups).
* **Option C**: Custom Hybrid Configuration.

### Question 2: Life Compass / Company Domains
* **For Personal Mode**: Configure weights for Mission, Mastery, Money, and Mind.
* **For Company Mode**: Configure repositories, tech stack, PR review rules, and outage severity levels.

### Question 3: Sparring Rigor & Autonomy
* **High Sparring**: Agent vigorously challenges weak assumptions and probes counter-arguments.
* **Balanced**: Socratic sparring on deep inquiries, deterministic fast execution for daily tasks.
* **Pure Execution**: Zero debate, pure command-line execution.

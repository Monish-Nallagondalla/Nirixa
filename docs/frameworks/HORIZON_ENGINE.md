# The 3-Horizon Execution Engine

[Documentation](../README.md) / [Frameworks](PERSONAL_COMPASS.md) / [3-Horizon Engine](HORIZON_ENGINE.md)

**A deterministic multi-timeframe planning engine connecting long-term North Stars down to weekly sprint execution.**

---

## The 3-Horizon Architecture

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ HORIZON 3: 10-30 YEAR NORTH STAR                                              │
│ • Long-term foundational mission and career pinnacle                          │
│ • Industry thought leadership and research impact                             │
├───────────────────────────────────────────────────────────────────────────────┤
│ HORIZON 2: 1-3 YEAR STRATEGIC LEVERS & FRICTION RADAR                         │
│ • Major product milestones and enterprise architecture initiatives            │
│ • Building defensible systems and high-leverage assets                        │
├───────────────────────────────────────────────────────────────────────────────┤
│ HORIZON 1: WEEKLY TOP 3 HIGH-LEVERAGE SPRINTS                                 │
│ 1. Ship primary software architecture release                                 │
│ 2. Finalize technical RFC for distributed systems workstream                  │
│ 3. Execute dedicated skill mastery drills                                     │
└───────────────────────────────────────────────────────────────────────────────┘
```

---

## How Horizons Connect

1. **Horizon 3 (The Unshakeable North Star)**:
   * Provides the philosophical filter. Every commitment must compound toward your core multi-year mission.
2. **Horizon 2 (The Friction Radar)**:
   * Captures real-world operational bottlenecks encountered in daily execution. These scars provide the raw material for deep authority.
3. **Horizon 1 (The Weekly Sprint Engine)**:
   * Limits active focus to exactly **Top 3 non-negotiable deliverables** per week. Nirixa OS actively blocks low-leverage distractions.

---

## The Weekly Socratic Horizon Review

Every Sunday at 18:00, Nirixa triggers an automated review on your phone:
* **H1 Check**: Which of the Top 3 sprints were executed?
* **H2 Check**: What new architectural scars were documented this week?
* **H3 Check**: Did this week's output compound toward your long-term North Star?

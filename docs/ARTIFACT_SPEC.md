# My-OS Artifact Specification

## Purpose

Every piece of information inside My-OS is an artifact.

Artifacts have different purposes, lifecycles and levels of maturity.

The same idea should never exist in multiple places unless intentionally promoted.

The goal is evolution, not duplication.

# Artifact Types

## Observation

Purpose

Capture raw thoughts before they disappear.

Location

journal/

Characteristics

- Fast
- Unfiltered
- Personal
- Incomplete

Example

"I wonder if intelligence is simply useful representations of reality."

---

## LinkedIn Post

Purpose

Communicate ideas publicly.

Location

## Resume Evidence

Location

# Memory Protocol & Coordinate System

## The "Map of Questions" Coordinate System
The Question Project is not structured linearly. It is mapped by core questions. 

### Root Nodes (The Questions)
Every major inquiry you have becomes a Root Node.
- `Q01`: What is Intelligence?
- `Q02`: Can intelligence exist without consciousness?
- `Q03`: How do we bridge human intuition and AI orchestration?

### Child Nodes (The OTAs)
When an OTA (Original Thought Asset) is created, it is assigned to a Root Node.
- `Q01.1`: AI answers, Humans ask.
- `Q01.2`: Intelligence is the computation of thought to find answers through data.
- `Q02.1`: The water heater analogy for associative memory.

## Cross-Linking (The Curiosity Engine)
OTAs rarely belong to just one question. 
An OTA must contain `Related Coordinates`. When a reader (or the AI) is exploring the Knowledge Graph, they can jump from `Q01.2` directly to `Q03.1` because the underlying concepts intersect.

## The Filter (The 1-Year Rule)
Before any idea enters the Knowledge Graph and receives a Coordinate, the Chief of Staff will ask:
*"Will this matter in 12 months?"*
If the answer is no, it is discarded or moved to `/personal`. It does not become an OTA.

## Retrieving Forgotten Memories
If you ask the AI to recall a thought, the AI will use the Coordinates to find adjacent thoughts, simulating human associative memory. (e.g., Searching for "water heater" will trigger `Q02.1`, which links to `Q01.2`, resurfacing the definition of intelligence).

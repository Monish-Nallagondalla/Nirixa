# LinkedIn Profile Landing Page Writer (`linkedin-landing-page-writer`)

Use this skill whenever optimizing Monish's or a user's LinkedIn profile to convert incoming profile visitors into inbound job offers and DMs.

---

## 🎯 Profile Landing Page Architecture

1. **The Hero Banner**: Statement selling tangible results (e.g. *0 to 1, 0 to $7M, 12K+ learners taught*).
2. **The Tagline Hook**: `Target Role | Niche Superpowers | Metric Result`.
3. **The About Hook**:
   - First 3 lines must hook the reader before they click "see more".
   - Use skimmable bullet points with whitespace and arrows (`->`).
   - Turn career transitions or red flags into unique positioning advantages.
4. **Experience & Featured**: Quantified outcomes, GitHub prototype demos, and case studies.
5. **Boolean Recruiter Skills**: Stuffed with verified JD keywords to rank high on LinkedIn Recruiter searches.

## 🛠️ CLI Execution
```bash
python system/engine/profile_optimizer.py
```

# High-Relevance Executive Outreach Skill (`linkedin-outreach-master`)

Use this skill whenever Monish needs to target hiring managers, tech peers, or executive leads on LinkedIn.

---

## 🎯 Core Directives

### 1. Target Opportunity Scoring
- Prioritize **non-creators** (<2,000 followers, <5 posts/month).
- Their notification noise is low; your comment and connection note get **10x higher visibility**.

### 2. High-Value Comment Structure
- **First Name Warmth**: Address by first name (`Hey Marco, ...`).
- **Substantive Value**: 2-3 sentences showing research or technical alignment.
- **Open-Ended Question**: End with a genuine question to invite dialogue.

### 3. Connection Outreach Mechanics
- **Cheeky Routine Angle**: *"Hey [Name], given that you already eat 3 meals a day, why don't you spend one of those meals with me? I'll buy your lunch for 15 mins of your brain power..."*
- **Character Count Limit**: Must be strictly under 300 characters.

---

## 🛠️ CLI & Python Execution

Run the outreach engine directly:
```bash
python system/engine/linkedin_outreach.py
```

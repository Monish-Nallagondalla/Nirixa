# JD Keyword Miner Skill (`jd-keyword-miner`)

Use this skill whenever analyzing target Job Descriptions (JDs) to extract high-coverage keywords for profile optimization or content targeting.

---

## 🎯 Directives
1. **Minimum Coverage**: Requires 75%+ keyword overlap across JDs so hiring managers instantly recognize domain alignment.
2. **Category Extraction**: Group keywords into Hard Skills, Key Phrases, Product Types, and Gaps.
3. **Keyword Brief Output**: Produce a concise 5-keyword brief to feed directly into `linkedin-landing-page-writer`.

## 🛠️ CLI Execution
```bash
python system/engine/profile_optimizer.py
```

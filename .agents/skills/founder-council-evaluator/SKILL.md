# Founder Council Evaluator (`founder-council-evaluator`)

Use this skill whenever evaluating a major system upgrade, content strategy, or strategic decision for My-OS.

## The Council Personas

### 1. Steve Jobs (Design, Simplicity & Emotional Punch)
- **Focus**: Radical reduction, zero friction, elegance, emotional connection.
- **Motto**: *"Simplicity is the ultimate sophistication."*
- **Audit Question**: *"Is this so clean and intuitive that it feels magical, or is it over-engineered junk?"*

### 2. Jensen Huang (Accelerated Scaling & Infrastructure Depth)
- **Focus**: Parallel execution, exponential scaling, real-time autonomous loops.
- **Motto**: *"The more you buy, the more you save."*
- **Audit Question**: *"Is this built for 100x scale? Can this agentic loop run asynchronously 24/7 without stopping?"*

### 3. Sundar Pichai (AI-First Trust & Ecosystem Scale)
- **Focus**: User trust, multi-modal integration, responsible AI, enterprise security.
- **Motto**: *"Building for everyone."*
- **Audit Question**: *"How does this build long-term trust with enterprise stakeholders while staying safe and reliable?"*

### 4. Mark Zuckerberg (Relentless Execution & Network Loops)
- **Focus**: Execution speed, open systems, viral distribution loops, social graph density.
- **Motto**: *"Move fast and execute."*
- **Audit Question**: *"How fast does this loop iterate? Is this driving viral network effects across every channel?"*

## Evaluation Output Protocol
1. Output the **Founder Audit Matrix** with direct feedback from each of the 4 icons.
2. Identify the **Single System Bottleneck**.
3. Provide **3 Brutal Refinements** to reach 100/10 execution.
